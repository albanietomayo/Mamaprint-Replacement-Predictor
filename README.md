# Mammaprint Replacement Predictor
Machine-learning surrogate model for MammaPrint risk classification using TCGA-BRCA RNA-seq data.
This project reproduces the Low-Risk vs High-Risk MammaPrint classification using transcriptomic data and supervised machine-learning models including GLMNET (LASSO), Random Forest, SVM, and GBM.

1. Overview
This repository contains a complete workflow to build a surrogate predictor of the MammaPrint assay using RNA‑seq expression data from the TCGA‑BRCA cohort.
The goal is to reproduce the Low‑Risk vs High‑Risk classification generated by the original 70‑gene MammaPrint signature, using machine‑learning models trained on public transcriptomic data.

The project is divided into two stages:

>> Part I — Data preparation and MammaPrint scoring

    - Selection of ER+ (Luminal A/B) breast cancer samples

    - Gene annotation and EntrezID mapping

    - Calculation of MammaPrint surrogate risk using gene70()

    - Construction of ML‑ready matrices
    
>> Part II — Machine‑learning model training and evaluation

    - Preprocessing, scaling, and feature filtering

    - Stratified data partitioning (70/30)

    - Training of RF, GLMNET (LASSO), SVM, and GBM models

    - Internal (cross‑validation) and independent hold-out validation

    - ROC curves, AUC, confusion matrices, and prediction tables

5. Data description:
The analysis uses publicly available data from TCGA‑BRCA, including:

  - RNA‑seq normalized expression matrix (17,497 genes × 983 samples)
  - Clinical metadata (114 variables × 983 patients)
  - ER+ subset, Luminal A/B (759 samples used for MammaPrint scoring and ML training)

Raw TCGA files are not included due to size limitations. Scripts and representative processed outputs are provided to reproduce the workflow.

6. Part I — MammaPrint surrogate scoring
 
 6.1. ER+ sample selection
      > Samples are filtered using: clinical$er_status_by_ihc == "Positive"
      > Resulting dataset: 759 ER+ patients.

 6.2. Matrix alignment
      > Row/column matching ensures:
         - (clinical) rows correspond to
         - (mat) columns (expression matrix)
 
 6.3. Gene annotation
      > Entrez IDs are retrieved using: mapIds(org.Hs.eg.db, keys = colnames(mat), column = "ENTREZID")

 6.4. MammaPrint surrogate calculation
      > The surrogate risk is computed with: risk <- gene70(data = mat, annot = entrezIds, do.mapping = TRUE)
      > Outputs:
            - MP_risk (LowRisk / HighRisk)
            - MP_score (continuous score)

 7. Part II — Machine‑learning models.

  7.1. Data partitioning
      > A stratified split (70/30) is performed using:  createDataPartition(riesgo, p = 0.7)

  7.2. Preprocessing
      > Centering and scaling
      > Removal of zero‑variance features
      > Removal of highly correlated predictors
      > Final matrix: filteredVar (12k+ predictors)
  
  7.3. Models trained
      > All models use:
           - 10‑fold cross‑validation
           - Internal evaluation with MLeval
           - Independent hold-out validation with pROC
      > Random Forest (RF)
           - Best mtry = 50
           - AUC (internal): ~0.92
           - AUC (validation): ~0.9167
      > GLMNET (LASSO)
           - Best lambda = 0.0001
           - AUC (internal): ~0.97
           - AUC (validation): ~0.96
           - Best-performing model
      > SVM (Radial)
           - Tuned over C and sigma
           - Strong performance, slightly below GLMNET
      > GBM
          - Tuned over trees, depth, shrinkage
          - High AUC, more complex model

10. Limitations
This project was developed as a learning exercise in transcriptomic machine learning using TCGA-BRCA data.

Some methodological limitations include:
- absence of biological feature-importance interpretation
- limited model explainability analysis
- use of a single validation split
- simplified hyperparameter optimization due to computational constraints

Future improvements would include:
- SHAP/feature importance analysis
- pathway enrichment of relevant genes
- nested cross-validation
- independent external cohorts
